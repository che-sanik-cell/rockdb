# ROCK·METAL·BASE — энциклопедия рок- и метал-музыки

**~233 000 групп** и **~18 700 сольных исполнителей** (гитаристы, певцы, барабанщики), **~33 000 музыкантов**, 855 направлений рока и метала.

## Запуск
```bash
pip install requests
python3 server.py          # http://localhost:8080
```

## Источники
| Что | Источник |
|---|---|
| Группы и сольные исполнители, жанры, годы, страны, составы, инструменты | Wikidata (CC0) |
| ~200 000 метал-групп: страна, жанр, статус, год основания | Encyclopaedia Metallum (metal-archives.com) |
| Подробный состав с ролями и годами, биография, фото и логотипы метал-групп | Metal Archives — подгружается при открытии карточки |
| Описания, фото | Википедия / Wikimedia Commons |
| Оборудование: гитары, басы, **усилители, кабинеты, педали эффектов**, звукосниматели, ударные, тарелки, клавишные, струны | извлекается из статей Википедии об участниках (`gear.js`, словарь из ~400 брендов и моделей) |

## Пересборка базы
```bash
python3 harvest.py       # Wikidata: группы, составы, музыканты
python3 harvest2.py      # Wikidata: сольные исполнители, ID Metal Archives
python3 harvest.py       # догрузить новых музыкантов
python3 supplement.py    # годы активности
python3 solo_filter.py   # убрать поп-исполнителей с единичным «поп-роком»
python3 ma_harvest.py    # Metal Archives: ~200k групп + годы (~30 мин)
python3 merge.py         # объединение (ma_band можно восстановить из ma_band.csv.gz)
```
